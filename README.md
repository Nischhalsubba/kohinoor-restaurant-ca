## Overview

A website for Kohinoor Restaurant (CA), showcasing the menu, location and contact information for the restaurant.

## Features

| ✔️ | Feature |
|---|---|
| ✅ | Menu section with dishes and prices |
| ✅ | Photo gallery of the restaurant and cuisine |
| ✅ | Contact form and reservation information |


## Tech Stack

- 🛠️ HTML
- 🛠️ CSS
- 🛠️ Bootstrap
- 🛠️ JavaScript

## Installation

Follow these steps to get a local copy of the project up and running:

1. Clone the repo: `git clone https://github.com/Nischhalsubba/kohinoor-restaurant-ca.git`.
2. Open `index.html` in your browser to view the site.

## Usage

Customize the menu items and photos to match your restaurant. Deploy the site to a hosting platform.
